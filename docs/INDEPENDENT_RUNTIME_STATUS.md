# Independent Runtime Status — Migration Lab

## الحالة الحالية

توجد الآن مسارات مستقلة تعمل بعميل Supabase Development وجلسة Supabase JWT، ولا تعتمد على `DashboardLayout` أو جلسة Manus في العرض نفسه: Dashboard، سجل الأرشيف، تفاصيل الترخيص، السلة، وإدارة الفريق. تمر العمليات الحساسة عبر RPCs محمية داخل PostgreSQL، ويُتحقق من الدور وحالة الاعتماد بواسطة `private.assert_approved_role`، مع بقاء RLS مفعلاً على الجداول.

| المجال | المسار المستقل | الحالة | ملاحظة |
|---|---|---|---|
| Dashboard | `/supabase-development/dashboard` | منقول جزئياً | المؤشرات الأساسية من `dashboard_operational`; تنبيهات النظام الكاملة مؤجلة. |
| سجل التراخيص | `/licenses?backend=supabase-development` | منقول جزئياً | القراءة والبحث والفلترة والترقيم من Supabase، لكن الغلاف الحالي مرتبط بالمسار العام. |
| الأرشيف | `/supabase-development/archive` | منقول جزئياً | بحث، نوع، حالة، وتاريخ الأرشفة من RPC. التصدير غير منقول. |
| الإنشاء | `/licenses/new?backend=supabase-development` | منقول جزئياً | إدخال يدوي وRPC idempotent؛ المرفقات وOffline غير مفعّلين في هذا المسار. |
| التفاصيل | `/supabase-development/licenses/:id` | منقول جزئياً | عرض، أحداث، Audit، تعديل، تجديد، أرشفة، تغيير رقم الأرشفة، وحذف ناعم/استعادة. |
| السلة | `/supabase-development/trash` | منقول | استعادة عبر RPC المدير فقط. |
| الفريق | `/supabase-development/team` | منقول جزئياً | قراءة وتعديل الدور وحالة الاعتماد عبر RPC المدير؛ إنشاء مستخدم جديد وإرسال دعوة مؤجل. |
| الطباعة/PDF/QR | `/supabase-development/licenses/:id/print` | منقول جزئياً | معاينة وطباعة وPDF تستخدم محول الصفوف الحالي؛ QR غير منقول بعد، والمرفقات خارج النطاق. |
| Offline/Online | المسار القديم فقط | غير منقول | الاختبارات موجودة، لكن ربط الطابور بمسار Supabase يحتاج عقد مزامنة مستقل. |
| AI/Forge | لا يُستخدم في العمليات اليومية | محظور عملياً | لا يدخل في الإدخال أو البحث أو CRUD أو الطباعة أو التزامن. |

## قرار المصادقة

لا يجوز حذف Manus OAuth من النسخة الحالية قبل نقل كل المسارات القديمة أو إنشاء نسخة مستقلة كاملة. لذلك تعتمد المسارات الجديدة على Supabase Auth عند وجود جلسة اختبار، وتبقى المسارات العامة الحالية Legacy/Fallback. لا توجد أسرار Service Role في العميل أو Worker adapter.

## قرار الوصول

هذه الحالة لا تعني أن المشروع صار مستقلاً بالكامل أو جاهزاً للنشر. يلزم نقل التصدير وOffline والتنبيهات وإنشاء دعوات الفريق وQR، ثم تنفيذ اختبار قبول مصادق عليه بحسابات اصطناعية قبل أي Preview خارجي. معاينة الطباعة وPDF أصبحت متاحة عبر المسار المستقل دون تغيير القالب الحالي. لم تُنشأ موارد Cloudflare ولم يُنفذ Deploy أو DNS أو Production migration.
