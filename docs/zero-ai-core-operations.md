# سياسة Zero-AI للعمليات الأساسية

**تاريخ التوثيق:** 22 أغسطس 2026  
**النطاق:** أرشيف التراخيص — إدخال وإدارة تراخيص المخازن والصيدليات.

## القاعدة المعمارية

تعمل العمليات اليومية الأساسية عبر المسار التالي فقط:

> الواجهة العربية → إجراءات tRPC المحمية → منطق الخادم البرمجي → MySQL أو التخزين الخاص بالمستندات.

لا يجوز أن تستدعي هذه العمليات نموذجاً لغوياً أو خدمة ذكاء اصطناعي أو واجهة API للذكاء الاصطناعي، سواء كان الاستدعاء مباشراً أو تلقائياً في الخلفية.

| العملية | طريقة التنفيذ المعتمدة |
|---|---|
| إدخال الترخيص وتعديله وحفظه | تحقق برمجي في الواجهة والخادم ثم كتابة إلى قاعدة البيانات |
| رقم الأرشفة | منطق خادمي برمجي وقيود قاعدة البيانات والمعاملة الذرية |
| البحث والتصفية والترقيم | استعلامات قاعدة بيانات وفهارس وترقيم صفحات |
| التنبيهات والإحصاءات | حسابات تاريخية واستعلامات COUNT وفلاتر برمجية |
| الأرشفة والاستعادة والحذف النهائي | صلاحيات مدير، تأكيد رقم الترخيص، وسجل تدقيق ضمن معاملة قاعدة بيانات |
| المستندات | تخزين خاص وروابط موقعة بعد التحقق من الصلاحية |
| الطباعة وPDF | قوالب وزارة ثابتة وإحداثيات معايرة بالمليمتر ومكتبات طباعة برمجية |
| CSV وExcel والتقارير العادية | بناء ملفات واستعلامات بيانات برمجية |

## نتيجة التدقيق

تم فحص مسارات التطبيق الفعلية وراوترات الخادم المستخدمة في التراخيص، إضافة إلى سجل طلبات الشبكة المتاح. لا توجد استدعاءات من هذه العمليات إلى LLM أو OpenAI أو Anthropic أو خدمات توليد صورة أو صوت. توجد ملفات بنية تحتية اختيارية عامة للذكاء الاصطناعي في القالب، لكنها غير مستوردة في راوترات التراخيص ولا توجد لها صفحة أو مسار في التطبيق الإنتاجي.

## حماية مستقبلية

أُضيف اختبار تلقائي يفحص ملفات العمليات الأساسية ويمنع استيراد أو استدعاء واجهات الذكاء الاصطناعي فيها. أي ميزة ذكاء اصطناعي مستقبلية، إن طلبها المستخدم صراحة، يجب أن تكون صفحة مستقلة اختيارية ولا تدخل تلقائياً في الإدخال أو الحفظ أو البحث أو الطباعة أو التقارير أو إدارة المستندات.
