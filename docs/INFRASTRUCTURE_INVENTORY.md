# جرد البنية التحتية — Migration Lab

**نطاق الجرد:** Development/Migration Lab فقط، بتاريخ 25 أغسطس 2026.

| المكون | الحالة | حدود الاستخدام |
|---|---|---|
| React + Vite + TypeScript | يعمل محلياً في Migration Lab | لا تغيير لتطبيق Production. |
| Express + tRPC | يعمل كمسار MySQL/tRPC الحالي وجسر Supabase | يبقى للرجوع التدريجي؛ لا يعد بديلاً منشوراً عن Cloudflare بعد. |
| MySQL + Drizzle | المصدر التشغيلي الافتراضي | لم تُنقل بيانات منه. |
| Supabase Development | قاعدة منفصلة بحسابات وبيانات اختبار | RLS وRPC وAudit وIdempotency فعالة. |
| Cloudflare | فحص قراءة فقط سابقاً | لا Pages أو Workers أو DNS أو Domain أو Deploy جديد ضمن هذا العمل. |
| Storage | غير مستخدم في مسار Supabase | لا جداول مرفقات أو رفع ملفات أو ملفات حقيقية. |
| AI | غير مستخدم في العمليات اليومية | لا إدخال أو بحث أو طباعة أو تصدير يعتمد على AI. |

## معلومات لا تدخل في ملفات النقل

لا تضمن أي أرشفة قابلة للمشاركة ملفات `.env` أو مفاتيح Supabase أو JWT أو بيانات حسابات أو ملفات جلسات المتصفح. تستخدم الواجهة فقط متغيرات العميل العامة اللازمة للاتصال بـSupabase Development؛ أما المفاتيح الإدارية فتبقى داخل الخادم/البيئة ولا ترسل للمتصفح.
